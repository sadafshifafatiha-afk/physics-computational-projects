# CIFAR-10 Neural Network Image Classifier

**Field:** Machine Learning / Computer Vision  
**Tools:** Python, TensorFlow / Keras, NumPy, Matplotlib

## Overview
This project implements a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset into 10 distinct categories (e.g., airplanes, automobiles, birds, cats).

## Objective
To build, train, and evaluate a deep learning model for image classification while analyzing performance metrics such as accuracy and loss.

## Methodology
1. **Data Preprocessing:** Normalized image pixel values and reshaped dataset inputs.
2. **Model Architecture:** Constructed a CNN with Convolutional, MaxPooling, Dropout, and Dense layers.
3. **Training & Evaluation:** Trained using the Adam optimizer and sparse categorical cross-entropy loss.
